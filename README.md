# hao-backprop-test

Test project for backprop integration. A minimal Python 3.12 / Flask 3.1.3 HTTP server that responds with `Hello, World!\n` to all HTTP requests on `127.0.0.1:3000`.

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

The server binds to `127.0.0.1:3000` and responds with `Hello, World!` (with trailing newline) to every HTTP method and URL path.
